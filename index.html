引言

欢迎来到我的个人主页。这里可以放你的个人介绍、从业经历、服务方向，或者旧 WordPress 网站里最重要的一段文字。

这个版本适合放在 GitHub Pages 上免费发布：没有后台、没有数据库，但打开快、维护简单，也很适合做个人名片、作品入口和简历展示。你可以先看一下作品展示区域。

作品

这里可以展示你过去网站里的图片、案例、文章入口或服务项目。建议从旧站的 wp-content/uploads 里挑选 3 到 8 张最能代表你的图片，压缩后放进 images 文件夹。

示例栏目：个人作品、项目案例、活动照片、文章精选、服务介绍。后续我可以继续帮你把旧网站里的图片和文字整理进来。

关于

这里适合写一段更完整的个人介绍：你是谁、擅长什么、过去做过什么、希望别人如何联系你。文字不需要很多，保持真诚和清楚就很好。

如果你愿意保留旧网站的风格，我们也可以把原网站的主色、背景图、字体感觉和内容结构提取出来，做成这个模板的专属版本。

联系

GitHub Pages 是静态网站，不能直接处理表单提交。最简单可靠的方式是放邮箱、社交主页、微信二维码或其他联系方式。
