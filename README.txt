个人主页模板

这是基于 HTML5 UP Dimension 改好的静态个人主页，可以免费发布到 GitHub Pages。

本地预览：
直接双击 index.html 即可打开。

常用修改：
1. 修改 index.html 里的姓名、简介、作品、联系方式。
2. 替换 images/bg.jpg 可以更换首页大背景图。
3. 替换 images/pic01.jpg、pic02.jpg、pic03.jpg 可以更换栏目图片。
4. 邮箱链接在 index.html 里搜索 your-email@example.com 后替换。

发布到 GitHub Pages：
1. 登录 GitHub。
2. 新建仓库，仓库名使用 你的用户名.github.io。
3. 上传本文件夹里的所有文件和文件夹。
4. 打开仓库 Settings -> Pages。
5. Source 选择 Deploy from a branch，Branch 选择 main，目录选择 /root。
6. 等待发布完成后访问 https://你的用户名.github.io/。
