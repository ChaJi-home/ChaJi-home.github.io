羽毛结构与光影

让细密的结构，
呈现轻盈的质感。

01 / STRUCTURE STUDY

先读结构，再看质感。

同一项研究的两个观察角度：视口图呈现羽枝走向，渲染图呈现细丝之间的明暗与空间。

STRUCTURE 结构视口 · 羽枝走向与疏密

RENDER 优化渲染 · 光影与细节层次

01 / AXIS

羽轴：形态的主线

由根部向尖端延伸的中轴建立整体方向，弧度让轮廓带有张力。明亮的轴线同时成为画面的视觉支点。

02 / RHYTHM

羽枝：秩序中的变化

两侧细密羽枝沿主线展开。连续排列形成羽片，局部间隙、弯曲与末端散开，让边缘保留自然的呼吸感。

03 / TRANSITION

绒羽：从紧密到松散

根部更短、更弯曲的细丝形成蓬松团簇，与上部清晰的羽片建立对比。疏密的渐变让形态过渡更柔和。

02 / VISUAL DEVELOPMENT

用明暗，读出细丝的层次。

黑底压低环境信息，让注意力集中在结构本身。亮部呈现方向，暗部保留细丝之间的距离。

01

轮廓的清晰度

羽毛边缘与黑色背景形成鲜明反差，末端分叉、弯曲和散开的羽枝成为第一层细节。

02

白色内部的层次

羽片以银灰色中间调连接高光和阴影，避免整片白色失去结构。细丝的方向变化由明暗节奏表现。

03

根部的轻盈感

主体紧密、根部松散。交叠的绒羽和局部透出的黑底，让轻薄与体积同时成立。

03 / PROCEDURAL BREAKDOWN

从一根主轴，生长出两侧羽枝。

把结构拆成采样、轮廓、局部坐标系与宽度四层控制。下面以独立 VEX 示例演示生成逻辑，可作为类似羽毛的搭建起点。

01 / SAMPLING

沿羽轴确定生长位置

用归一化坐标 t 标记根部到尖端的位置；避开底端裸露羽管，分别在主轴两侧生成曲线。增加采样数量会增加羽枝密度，不改变整体轮廓。

C(t) = (0, L·t, bend·sin(π·t))
t ∈ [0.05, 0.97]
02 / SILHOUETTE

用包络约束羽片外形

正弦包络控制两端收窄、中段展开。指数小于 1 时外形更饱满；每根羽枝叠加固定种子的长度变化，避免两侧完全机械对称。

span(t) = halfwidth · sin(π·t)^0.72
length_jitter ∈ [0.90, 1.06]
03 / LOCAL FRAME

把侧向展开与向上扫掠分开

T 表示轴线切向，B 表示横向，N 表示法向。u 沿单根羽枝从根部走向末端；侧向位移决定宽度，切向位移决定羽枝向尖端收拢的程度。

P(t,u) = C(t) + side·B·span·u
       + T·sweep·span·u^1.35
       + N·displacement·u²
04 / WIDTH & MASK

根部锁定，末端渐细

扰动乘以 u²，让根部位置保持不动，变化集中在末端。宽度沿曲线衰减；根部区域另用平滑遮罩加强卷曲，建立紧密羽片与松散绒羽的过渡。

width(u) = max(0.00004,
               barbwidth·(1-u)^1.5)
down(t) = 1 - smooth(0.12, 0.32, t)
PARAMETER LAB / 轮廓参数示意

同一套规则，不同的形态。

拖动参数观察羽枝密度、羽片宽度与扫掠的关系。这里仅显示二维轮廓，不包含代码中的随机长度、出平面扰动、材质和灯光。

VEX / DETAIL WRANGLE

曲线羽毛生成示例

下载 VEX 示例 ↘

在空 Geometry 中建立 Attribute Wrangle，Run Over 设为 Detail（only once），粘贴下方代码。示例为本页补充的独立生成算法，并非原工程代码；输出普通多段线，不包含羽小枝钩连或最终渲染设置。

参数示例值控制内容
pairs / segments180 / 24每侧 180 根羽枝，每根 24 段；参数决定几何密度。
halfwidth / sweep0.22 / 0.28羽片宽度与向尖端弯扫的趋势。
bend / disorder0.09 / 0.012主轴出平面弯曲与羽枝局部扰动。
barbwidth / seed0.0007 / 7细丝宽度与可重复的随机变化。
展开完整 VEX 代码 ＋
// Feather study / Detail Wrangle / Run Over: Detail (only once)
// Use an empty Geometry input. This creates ordinary open polylines.
// Demonstration rebuilt for the case study; not the original project's code.
// Does not create SideFX condensed feathers or microscopic hooked barbules.
int pairs = 180;
int segments = 24;
int seed = 7;
float length = 1.0;
float halfwidth = 0.22;
float bend = 0.09;
float sweep = 0.28;
float disorder = 0.012;
float barbwidth = 0.0007;
float PI = 3.141592653589793;

addpointattrib(0, "width", 0.0);
addpointattrib(0, "curveu", 0.0);
addpointattrib(0, "root_t", 0.0);
addprimattrib(0, "side", 0);

// 01 / A sampled shaft: C(t) = (0, L*t, bend*sin(PI*t)).
int shaft = addprim(0, "polyline");
setprimgroup(0, "shaft", shaft, 1);
for (int j = 0; j <= 64; j++)
{
    float t = float(j) / 64.0;
    vector C = set(0.0, length*t, bend*sin(PI*t));
    int pt = addpoint(0, C);
    addvertex(0, shaft, pt);
    float w = max(0.00015, 0.008*pow(1.0-t, 1.3));
    setpointattrib(0, "width", pt, w, "set");
    setpointattrib(0, "curveu", pt, t, "set");
}

// 02 / Two barbs per station; each barb has its own stable random seed.
for (int i = 0; i < pairs; i++)
{
    float t = fit(float(i), 0.0, float(pairs-1), 0.05, 0.97);
    vector C = set(0.0, length*t, bend*sin(PI*t));
    vector T = normalize(set(0.0, length, bend*PI*cos(PI*t)));
    vector B = set(1.0, 0.0, 0.0);
    vector N = normalize(cross(B, T));
    float envelope = pow(max(0.0, sin(PI*t)), 0.72);
    float down = 1.0 - smooth(0.12, 0.32, t);

    for (int side = -1; side <= 1; side += 2)
    {
        float r = rand(float(i*37 + side*19 + seed*101));
        float span = halfwidth * envelope * fit01(r, 0.90, 1.06);
        int prim = addprim(0, "polyline");
        setprimgroup(0, "barbs", prim, 1);
        setprimattrib(0, "side", prim, side, "set");
        for (int j = 0; j <= segments; j++)
        {
            float u = float(j) / float(segments);
            // Lateral spread + tipward sweep + a coherent local ripple.
            float n = noise(set(t*8.0, u*5.0, float(seed+side))) - 0.5;
            vector P = C + float(side)*B*span*u
                         + T*sweep*span*pow(u, 1.35);
            float curl = down * 0.025 * sin(u*PI*3.0 + r*PI*2.0);
            P += N * (disorder*n + curl) * u*u;
            int pt = addpoint(0, P);
            addvertex(0, prim, pt);
            float w = max(0.00004, barbwidth*pow(1.0-u, 1.5));
            setpointattrib(0, "width", pt, w, "set");
            setpointattrib(0, "curveu", pt, u, "set");
            setpointattrib(0, "root_t", pt, t, "set");
        }
    }
}

从示例到渲染，需要补齐什么？

  1. 曲线输出保留 shaft、barbs 分组与 width 属性，先检查轮廓及末端连续性。
  2. 细节补充当前例子只生成主轴与一级羽枝。更细的羽小枝、聚束、分叉和局部断裂需继续构建。
  3. 渲染交接使用渲染器支持的曲线宽度设置；若走多边形路径，可先用 Sweep 生成细管，再控制分段与半径。
  4. 近景检查检查细丝高光是否过曝、轮廓是否锯齿、尖端是否过粗，以及密集区域的采样噪点。
